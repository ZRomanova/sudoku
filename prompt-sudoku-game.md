# Промпт для Claude Code: судоку с кастомными регионами

## Общая идея

Мобильная (телефон, touch-first) офлайн-игра, полностью локальная, без сервера и сети, для личного использования одним пользователем. Два режима: **Конструктор регионов** и **Прохождение судоку**. Судоку генерируется на регионах произвольной формы (вместо стандартных квадратов 3×3), которые пользователь рисует сам. Дизайн — минималистичный, 2D, абстрактная геометрия. Игра не должна создавать ощущение затягивания: никакого давления, таймеров, уведомлений — только спокойное прохождение с возможностью прерваться в любой момент.

## Технологии

- Нативное Android-приложение: Kotlin + Jetpack Compose для UI.
- Локальное хранение данных — Room (SQLite) для сохранённых раскрасок и текущего состояния партии; никакого бэкенда, аккаунтов или сетевых запросов.
- Приложению не нужны сетевые разрешения — оно должно работать полностью офлайн по умолчанию.
- Архитектура на твоё усмотрение (например, простой MVVM), но без избыточного оверинжиниринга — проект личный, некрупный.
- Портретная ориентация в приоритете, интерфейс адаптирован под touch и разные размеры экранов телефонов.

## Режим 1: Конструктор регионов

### Рисование

- Поле 9×9 клеток.
- Палитра из 9 цветов + ластик; всегда виден активный выбранный инструмент.
- Тап по клетке красит её в активный цвет (или стирает, если выбран ластик).
- Клетку можно перекрасить в другой цвет прямо поверх, без использования ластика.
- Счётчик клеток по каждому из 9 цветов (X/9). Как только у цвета набрано 9 клеток, он становится недоступен для выбора, пока не освободится место (перекраска/стирание клетки этого цвета).
- Черновики не поддерживаются: раскраска либо доводится до конца (все 81 клетка закрашены, ровно по 9 на цвет), либо не сохраняется.

### Валидация

- Во время рисования — только блокировка превышения лимита 9 клеток на цвет, без проверки логики судоку в реальном времени.
- После завершения раскраски — по кнопке «Сгенерировать»/«Сохранить» запускается проверка: можно ли на этих 9 регионах построить корректную судоку (каждая цифра 1–9 один раз в строке, столбце и регионе) с существующим решением.
- Если раскраска невалидна — понятное сообщение об ошибке, пользователь возвращается к раскраске и правит её вручную (без автоисправления со стороны игры).

### Сложность

- Выбор одного из 3 уровней сложности перед сохранением/генерацией.
- Сложность зависит и от количества открытых чисел, и от того, какие техники решения требуются: лёгкий уровень должен быть объективно быстрее решаем (больше открытых чисел и/или только простые техники), сложный — медленнее (меньше открытых чисел и/или требуются более продвинутые приёмы). Конкретный алгоритм калибровки сложности и генерации — на твоё усмотрение.

### Библиотека сохранённых раскрасок

- Список сохранённых валидных раскрасок, у каждой — превью формы регионов (миниатюра сетки с цветами) и кнопка «Играть».
- Кнопка «Играть» каждый раз генерирует новую случайную головоломку на этой раскраске (новое случайное валидное заполнение + новый набор открытых чисел под выбранную сложность). Повторная генерация никогда не повторяет предыдущую партию буквально — только форма регионов переиспользуется, сама головоломка каждый раз свежая.

## Режим 2: Прохождение

- Стандартный ввод цифр 1–9 в клетки судоку.
- Любую введённую пользователем цифру можно стереть в любой момент.
- Никаких заметок-кандидатов, подсказок, проверки ошибок в реальном времени, таймера, индикаторов прогресса — ничего, что создаёт давление или усложняет интерфейс.
- Исходные данные (givens) и цифры, введённые пользователем, визуально различаются только типографикой (например, разная насыщенность/начертание шрифта), а не цветом. Сами цифры — чёрные/белые, на контрастном фоне (с учётом цвета региона под клеткой, чтобы оставаться читаемыми).

## Пауза и возврат

- Автосохранение прогресса после каждого хода (введённая или стёртая цифра).
- При открытии игры пользователь всегда попадает ровно туда, где остановился — только текущее состояние поля, без дополнительных индикаторов прогресса.

## Визуальный стиль

- Минимализм, 2D, абстрактная геометрия.
- 9 хорошо различимых между собой цветов для регионов (поддержка дальтонизма не требуется — личный проект).
- Чистая типографика, спокойная палитра, без анимаций и эффектов, которые отвлекают или создают ощущение затягивания.

## Нефункциональные требования

- Полностью офлайн, ни одного сетевого запроса.
- Один пользователь, без аккаунтов и авторизации.
- Все данные хранятся только локально на устройстве и не теряются между сессиями.
- Оптимизация под маленький экран телефона и touch-интерфейс.

## Структура приложения

1. Главный экран: выбор между «Конструктор» и «Мои раскраски / Играть».
2. Экран конструктора: сетка 9×9 + палитра + счётчики + выбор сложности + кнопка «Сгенерировать и сохранить».
3. Экран библиотеки: список сохранённых раскрасок с превью и кнопкой «Играть».
4. Экран игры: судоку-поле с раскрашенными регионами, ввод/стирание цифр, автосохранение.

## С чего начать

1. Базовая структура Android-проекта (Kotlin, Jetpack Compose, Room для хранения).
2. Логика генерации судоку на произвольных регионах: проверка валидности региона (существует ли решение) и генерация случайного уникального решения + набора открытых чисел под уровень сложности.
3. UI конструктора: сетка, палитра, счётчики, валидация, сохранение.
4. UI библиотеки сохранённых раскрасок.
5. UI прохождения: ввод/стирание цифр, автосохранение, восстановление состояния при открытии.
