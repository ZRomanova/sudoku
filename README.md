# Судоку с произвольными регионами

Локальное офлайн-приложение для Android: обычное судоку 9×9, но регионы — не классические квадраты 3×3, а произвольные фигуры из 9 клеток, которые вы рисуете сами в конструкторе. Личный проект для одного пользователя, без сети, аккаунтов и рекламы.

**[Скачать готовую сборку (APK)](releases/sudoku-1.0-debug.apk)** — установите файл на телефон и разрешите установку из неизвестных источников, если Android об этом спросит.

## Возможности

- **Конструктор регионов** — рисование 9 регионов пальцем (тап или проведение по нескольким клеткам сразу). Игра в реальном времени подсказывает недоступные клетки — те, что точно сделают раскладку нерешаемой, — и не даёт их закрасить. Перед сохранением раскладка дополнительно проверяется полным решением судоку.
- **Советы по конструктору** — короткая памятка простым языком, как собрать регионы, чтобы раскладка точно получилась валидной.
- **Библиотека раскладок** — список сохранённых раскладок с превью формы, переименованием и удалением.
- **Игра** — ввод и стирание цифр, автосохранение после каждого хода, восстановление партии ровно там, где остановились. Никаких таймеров, подсказок и индикаторов прогресса, которые создают давление.
- **Случайная игра** — быстрый старт на случайной сохранённой раскладке с выбором сложности; работает, даже если пользователь удалил все раскладки (в этом случае используется классическое судоку).
- **Статистика** — процент успешно завершённых партий отдельно по каждой раскладке и уровню сложности; не завершённые до конца партии в статистику не попадают.
- Три уровня сложности генерации (лёгкий/средний/сложный), калибруемые и по числу открытых клеток, и по требуемым техникам решения.

## Технологии

- Kotlin + Jetpack Compose (Material 3)
- Room (SQLite) — единственное хранилище: сохранённые раскладки, текущая партия, история результатов
- Собственный backtracking-солвер судоку (`engine/SudokuSolver.kt`), работающий с произвольными регионами, а не только с классическими блоками 3×3
- Navigation Compose, простой MVVM (ViewModel + StateFlow), без DI-фреймворков — `AppContainer.kt` вручную собирает зависимости

## Структура проекта

```
app/src/main/java/com/zoya/sudoku/
├─ engine/          генерация и решение судоку: солвер, генератор, оценка сложности, произвольные регионы
├─ data/
│  ├─ db/           Room-сущности, DAO, миграции
│  └─ repository/   раскладки, текущая партия, статистика
└─ ui/
   ├─ home/         главный экран
   ├─ constructor/  рисование регионов + советы
   ├─ library/      библиотека сохранённых раскладок
   ├─ game/         экран прохождения судоку
   ├─ stats/        статистика по раскладкам и сложности
   ├─ components/   переиспользуемые composable (сетка, палитра, диалоги, миниатюры)
   └─ navigation/   маршруты и граф навигации
```

## Сборка и запуск

Требования: Android Studio (или Gradle из консоли) + JDK 17. `minSdk` 26, `targetSdk`/`compileSdk` 34.

```
./gradlew assembleDebug          # сборка debug APK
./gradlew testDebugUnitTest      # юнит-тесты движка судоку
adb install -r app/build/outputs/apk/debug/app-debug.apk   # установка на подключённое устройство
```

Приложение полностью офлайн и не требует сетевых разрешений или бэкенда.
